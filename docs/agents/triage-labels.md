# Triage Roles

The skills speak in terms of canonical triage roles. This repo uses those role names **verbatim** as
values in the Notion tracker (see [`issue-tracker.md`](./issue-tracker.md)) — there is no mapping to
apply. In Notion they are select/status values rather than labels.

Category roles: `bug` (something is broken), `enhancement` (new feature or improvement).

State roles: `needs-triage` (maintainer must evaluate), `needs-info` (waiting on the reporter),
`ready-for-agent` (fully specified, ready for an AFK agent), `ready-for-human` (requires human
implementation), `wontfix` (will not be actioned).

If a role and a tracker value ever diverge, record the mapping here.
